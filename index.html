Already on Maven? Install SHAFT · See agent-to-evidence workflow

Three lines in. A green report out.​

  1. Write

    QuickStartTest.java
    SHAFT.GUI.WebDriver driver = new SHAFT.GUI.WebDriver();
    driver.browser()
          .navigateToURL("https://shafthq.github.io/")
          .and().element().assertThat(By.cssSelector("h1")).isVisible();
    driver.quit();

  2. Run

    Terminal
    $ mvn test
    [INFO] Running hero.QuickStartTest
    [INFO] Tests run: 1, Failures: 0, Errors: 0, Skipped: 0
    [INFO] BUILD SUCCESS

  3. Prove

Common questions

Is SHAFT free to use?

Yes. SHAFT is open source under the MIT license.

Do I have to rewrite my Selenium tests?

No. Move an existing Maven suite onto current SHAFT and run one test first. Upgrade a project.

Which Java version do I need?

Java 25. Installation lists the rest.
