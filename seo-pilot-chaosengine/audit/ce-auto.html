ChaosEngine
عقد عمل يخلّي الـ agent شريك هندسة منضبط

نظام تشغيل محايد للمزوّد لشغل الـ agents: live research، خطة كاملة، تنفيذ متماسك، evidence قبل الادّعاء، owned delivery، durable learning — من غير ما يربط المشروع بـ model أو client واحد.

دليل التثبيت والتشغيل المستودع على GitHub

اتفرّج على الشرح المختصر

شرح ChaosEngine في أقل من دقيقة ونص — إيه هو ليه موجود. الترجمة الإنجليزية مفعّلة؛ الفيديو مش بيتحمّل غير لما تضغط تشغيل.

ليه موجود؟

الـ agents القوية لسه بتفشل بطرق متوقّعة: بتعدّل قبل ما تفهم، بتثق بملخّصات قديمة، وبتقف عند لافتة خضراء شكلها نجاح. ChaosEngine بيخلّي التسلسل الآمن صريح ومحمول.

1

Evidence first

اقرأ وشغّل الـ system الحقيقي قبل أي ادّعاء.

2

Research before edit

رجّع قرارات سابقة، افحص الـ callers الحاليين، وقارن مسارات قابلة للتنفيذ قبل أي edit.

3

Coherent delivery

كمّل الـ scope المعتمد كوحدة واحدة — من غير تقطيع على كل خطوة صغيرة.

4

Terminal challenge

بعد الـ commit النهائي وفحوصات الـ PR: مراجعة خصمية اختيارية (حد أقصى جولتين) ثم local tests إضافية.

5

Ownership

الشغل بيكمل خلال الـ review والفحوصات والـ merge المؤكد لما تكون السلطة ممنوحة.

6

Durable learning

الحقائق والقرارات القابلة لإعادة الاستخدام تروح لـ stores منظّمة؛ المحادثات والمادة الخاصة مش بتتحوّل لـ policy.

Operating loop

Task → live research → خطة للـ full scope → تنفيذ → final commit → CI → مراجعة اختيارية → extra tests → merge → Learning Session.

  1. Plan

    فرز المهمّة، استرجاع الـ context، خطة كاملة قبل أي كتابة code واسعة.

  2. Do

    تنفيذ الـ scope المعتمد كوحدة متماسكة.

  3. Check

    Evidence من النظام الحقيقي + فحوصات آلية.

  4. Act

    Delivery، تعلّم، وتحسين العقد نفسه.

Quick install

المسار الذهبي من INSTALL.md (macOS / Linux). التفاصيل، Windows في الدليل.

curl -fsSL "https://raw.githubusercontent.com/ShaftHQ/SHAFT_ENGINE/main/chaos-engine/install.sh" \
  | bash -s -- "https://raw.githubusercontent.com/ShaftHQ/SHAFT_ENGINE/main/chaos-engine/install.sh"
python3 .chaos-engine/install.py doctor --project .

الرخصة: MIT. المصدر: شجرة chaos-engine/ داخل ShaftHQ/SHAFT_ENGINE.
