نظبط العقلية

الأساسيات والعقلية

الـ SDLC والـ Agile، يعني إيه test automation، وإمتى يستاهل وإمتى لأ، والـ test pyramid والـ shift-left.

ندخل في العمق

إزاي تبقى SDET

سوق الشغل، والمسار من الصفر، وأساسيات الـ Java والـ OOP، وتجهيز JDK و IntelliJ IDEA و Maven.

ندخل في العمق

Selenium WebDriver عملي

الـ locators والـ waits والـ assertions مع TestNG، وبعدين Page Object Model وباقي الـ design patterns.

ندخل في العمق

Git، CI/CD، Selenium Grid

الـ Git و GitHub Actions والـ quality gates، وتشغيل الاختبارات على Selenium Grid مع تقارير واضحة.
